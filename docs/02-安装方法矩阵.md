# ROS1 安装方法矩阵

## 先给结论

本书主线采用 **Ubuntu 20.04 虚拟机或原生系统 + ROS Noetic 官方 apt 安装 + `ros-noetic-desktop-full`**。这是新手第一次学习 ROS1 时成功率最高、资料最一致、排障路径最清楚的组合。

其他安装方法必须讲，但不与主线等价：

- WSL2：适合 Windows 学生做 CLI、轻量 RViz 和前期实验，不建议把第一轮重载 Gazebo 实验押在 WSL2 上。
- Docker：适合课堂批量复现、助教备用环境、CI 和隔离环境，但图形、网络和硬件映射需要额外解释。
- 鱼香 ROS 一键安装：适合国内网络与课堂装机辅助，但不能替代官方安装原理。
- 源码构建：适合高级理解和后续跨架构部署铺垫，不作为新手主线。

## 方法对比

| 方法 | 推荐级别 | 适用对象 | 优点 | 限制 | 本书位置 |
|---|---:|---|---|---|---|
| Ubuntu 20.04 + 官方 apt | 主线 | 所有读者 | 官方路径清晰，资料最多，排障最直接 | 需要匹配 Ubuntu 20.04 | 第 3 章主流程 |
| Ubuntu 20.04 虚拟机 | 主线载体 | Windows/macOS 学生 | 易恢复、易截图、风险低 | 图形性能弱于原生 | 第 1、3 章 |
| 原生 Ubuntu 20.04 | 推荐 | 实验室机器、双系统学生 | 图形和硬件访问直接 | 安装系统风险更高 | 第 1、3 章 |
| WSL2 + Ubuntu 20.04 | 备用 | Windows 学生 | 与 Windows 共存，CLI 方便 | GUI、USB、Gazebo 体验依机器而异 | 第 3 章旁路 |
| Docker 官方 ROS 镜像 | 备用/助教 | 课堂批量环境、CI | 环境一致、可清理 | GUI、网络、设备映射复杂 | 第 3 章旁路 |
| 鱼香 ROS 一键安装 | 辅助 | 国内网络环境、安装失败后的辅助处理 | 自动换源、自动配置，降低安装失败率 | 自动化程度较高，内部步骤不够直观，必须回到官方原理解释 | 第 3 章辅助 |
| 源码构建 | 高级 | 教师、挑战实验、迁移预备 | 理解依赖和构建链 | 时间长，错误多，不适合首学 | 附录/挑战实验 |

## 官方 apt 安装主流程

适用前提：

- Ubuntu 20.04 Focal Fossa。
- 能访问 ROS 软件源或可使用镜像源。
- 学生使用 Bash 作为默认 shell。

推荐安装包：

- `ros-noetic-desktop-full`：包含 Desktop、2D/3D 仿真和感知包，最适合本书全流程。
- `ros-noetic-desktop`：包含 ROS-Base、rqt、RViz 等桌面工具，缺少部分仿真与感知包。
- `ros-noetic-ros-base`：只有 ROS 打包、构建和通信库，无 GUI 工具，适合服务器或机器人本体。
- `ros-noetic-PACKAGE`：按需安装单个包，例如 `ros-noetic-slam-gmapping`。

核心步骤应按官方文档写：

```bash
sudo sh -c 'echo "deb http://packages.ros.org/ros/ubuntu $(lsb_release -sc) main" > /etc/apt/sources.list.d/ros-latest.list'
sudo apt install curl
curl -s https://raw.githubusercontent.com/ros/rosdistro/master/ros.asc | sudo apt-key add -
sudo apt update
sudo apt install ros-noetic-desktop-full
echo "source /opt/ros/noetic/setup.bash" >> ~/.bashrc
source ~/.bashrc
sudo apt install python3-rosdep python3-rosinstall python3-rosinstall-generator python3-wstool build-essential
sudo rosdep init
rosdep update
```

验证命令：

```bash
rosversion -d
roscore
```

另开终端：

```bash
source /opt/ros/noetic/setup.bash
rosnode list
```

正确现象：

- `rosversion -d` 输出 `noetic`。
- `roscore` 正常启动。
- `rosnode list` 至少看到 `/rosout`。

## 虚拟机方法

推荐用于零基础课堂。教师应提供统一的 Ubuntu 20.04 ISO、虚拟机配置建议和快照恢复说明。

最低建议：

- CPU：2 核或更多。
- 内存：4 GB 起步，8 GB 更稳。
- 磁盘：40 GB 起步。
- 网络：NAT 足够完成前期学习。

教材必须讲清：

- 虚拟机是一个完整 Ubuntu 系统，不是容器。
- 快照可以在安装失败后恢复。
- Gazebo 运行慢不代表 ROS 安装错误。

## WSL2 方法

WSL2 可用于 Windows 学生的前期命令行学习。微软官方文档说明 WSL 支持 Linux GUI 应用，但机器人仿真涉及图形、显卡、网络和 USB 设备，体验可能不稳定。

教材写法：

- 可作为“Windows 学生备用路径”。
- 前期验证限制在 `roscore`、CLI、简单 RViz。
- Gazebo 和真实硬件接入不作为 WSL2 主验收目标。

## Docker 方法

Docker 适合作为课堂备用环境。官方 Docker Hub 有 ROS 镜像，OSRF 维护 docker image 定义仓库。

最小示例：

```bash
docker pull ros:noetic
docker run -it --rm ros:noetic roscore
```

教材必须解释：

- 容器不是虚拟机。
- 容器内文件默认会随容器删除，应使用 volume 保存工作空间。
- GUI 程序需要额外映射 X11/WSLg/Wayland。
- 访问真实串口、USB、雷达、摄像头需要设备映射和权限配置。

## 鱼香 ROS 一键安装

鱼香 ROS 一键安装工具可以降低国内网络环境下的安装门槛，也能辅助配置 rosdep 和系统源。教材应把它定位为“辅助工具”，而不是主线原理。

教材写法：

- 先讲官方 apt 流程，让学生知道软件源、key、apt、环境变量分别在做什么。
- 再讲一键安装解决的是换源、配置、自动化输入和常见网络失败。
- 排障时仍要能回到 `/etc/apt/sources.list.d/`、`~/.bashrc`、`rosdep`、`apt update` 等基础检查。

## 源码构建方法

源码构建不适合零基础学生第一次安装，但必须在教材中解释其意义：

- 理解 ROS 包依赖和构建顺序。
- 理解 `rosinstall_generator`、`vcs import`、`rosdep`、`catkin_make_isolated` 的作用。
- 为后续非 x86 架构上的 ROS1 部署研究建立概念基础。

教材中只给“挑战实验”级别，不作为每个学生必须完成的路径。

## 高频错误

| 错误现象 | 高概率原因 | 检查命令 |
|---|---|---|
| `Unable to locate package ros-noetic-desktop-full` | Ubuntu 版本不是 20.04，或 ROS 源未添加成功 | `lsb_release -a`; `cat /etc/apt/sources.list.d/ros-latest.list` |
| `roscore: command not found` | 没有安装成功，或没有 source 环境 | `which roscore`; `source /opt/ros/noetic/setup.bash` |
| `sudo rosdep init` 失败 | 网络、源、已有配置冲突 | `ls /etc/ros/rosdep/sources.list.d/` |
| 新终端找不到 ROS 命令 | `.bashrc` 没有 source Noetic | `tail ~/.bashrc` |
| WSL2 RViz 异常 | GUI/显卡/显示服务问题 | 先用 VM 或原生系统验证同一命令 |
