# 教材总纲

## 读者画像

本书面向没有 Ubuntu、Linux 命令行和 ROS 经验的大学生。默认读者知道基础编程概念，但不要求具备机器人系统开发经验。

读者完成本书后，应能做到：

- 解释 ROS 是什么、解决什么问题、不是传统操作系统的原因。
- 独立搭建 Ubuntu 20.04 + ROS Noetic 学习环境。
- 使用 ROS CLI 观察节点、话题、服务、参数和计算图。
- 创建 catkin 工作空间和功能包。
- 用 Python 和 C++ 编写基础发布者、订阅者、服务端、客户端。
- 使用 launch、YAML、参数服务器、rosbag、`roswtf` 和仿真时间管理可复现实验。
- 理解 TF、URDF、RViz、Gazebo 在机器人系统中的位置。
- 完成一个小型移动机器人仿真项目。

## 总体边界

本册只写 ROS1 基础。LoongArch64 部署、交叉编译、Yocto/meta-ros、源码移植和架构适配不进入正文，只在结尾作为下一阶段学习路线说明。

ROS2 只在必要处作为历史对照出现，例如解释 ROS1 已 EOL、现代新项目通常应评估 ROS2。正文不使用 ROS2、Colcon 或 Ubuntu 22.04 作为主线。

## 主线环境

- 操作系统：Ubuntu 20.04 Focal Fossa。
- ROS 发行版：ROS1 Noetic Ninjemys。
- 编程语言：Python 3、C++14。
- 构建系统：catkin，主命令使用 `catkin_make`。
- 图形工具：RViz、rqt、Gazebo Classic。
- 教学案例：turtlesim、beginner_tutorials、自定义移动机器人仿真包。

## 章节结构

### 第 1 章 Ubuntu 与 Linux 入门

先解决学生能否具备 Linux 基本操作能力的问题。内容包括 Ubuntu 发行版概念、桌面与终端、目录结构、权限、`apt`、文本编辑器、环境变量、Git、压缩包和常见网络问题。

最小实验：在终端完成目录创建、文件编辑、软件安装、环境变量查看和 Git 克隆。

### 第 2 章 ROS1 基本概念

解释 ROS 是机器人软件中间件和工具生态，不是传统操作系统。建立 ROS Master、Node、Topic、Message、Service、Action、Parameter Server 的基本模型。

最小实验：启动 `roscore`，用 `rosnode list`、`rostopic list`、`rosservice list`、`rosparam list` 观察空系统。

### 第 3 章 ROS1 安装方法完整说明

讲清楚安装不是只有一种做法。主线使用 Ubuntu 20.04 + 官方 apt 安装，旁路说明虚拟机、WSL2、Docker、鱼香 ROS 一键安装和源码构建。

最小实验：完成官方 apt 安装，验证 `roscore`、`rosversion -d`、`roscd`、`turtlesim_node`。

### 第 4 章 第一个 ROS 系统

用 turtlesim 让学生第一次观察节点、话题、消息和计算图。重点不是控制 turtlesim 模拟海龟本身，而是通过工具观察数据流。

最小实验：运行 `turtlesim_node` 和 `turtle_teleop_key`，使用 `rqt_graph`、`rostopic echo`、`rostopic pub` 观察和控制系统。

### 第 5 章 catkin 工作空间与功能包

建立 ROS 项目组织能力。讲清楚 `catkin_ws/src`、`package.xml`、`CMakeLists.txt`、`devel/setup.bash`、依赖声明和 source 顺序。

最小实验：创建 `beginner_tutorials` 包，编译后用 `rospack find` 和 `rosrun` 验证。

### 第 6 章 Python 与 C++ 编写 ROS 节点

同一个通信案例分别使用 `rospy` 和 `roscpp` 实现。先用 Python 降低门槛，再用 C++ 解释工程项目中的编译、链接和类型检查。

最小实验：实现 talker/listener、add_two_ints 服务、参数读取和日志输出。

### 第 7 章 ROS 运行管理

把多个节点、参数和配置组织成可复现实验。重点讲 `roslaunch` 不是顺序脚本，YAML 参数、命名空间、remap、日志、rosbag、`roswtf` 和 `/clock` / `use_sim_time` 的作用。

最小实验：用一个 launch 文件启动 talker/listener，加载 YAML 参数，录制并回放 `/chatter`。

### 第 8 章 机器人坐标、模型与可视化

建立机器人系统里的空间关系。讲 TF 树、常见坐标系、URDF 结构、`robot_state_publisher`、`joint_state_publisher` 和 RViz。

最小实验：编写一个两轮差速机器人 URDF，在 RViz 中显示模型和 TF。

### 第 9 章 仿真与移动机器人入门

区分 RViz 和 Gazebo。使用 TurtleBot3 或同类开源案例作为移动机器人系统参考，讲速度话题、里程计、激光雷达、简单建图和导航概念。

最小实验：启动移动机器人仿真，查看 `/cmd_vel`、`/odom`、`/scan`，用键盘控制并观察 RViz。

### 第 10 章 综合项目

从零组织一个小型移动机器人仿真工作空间。项目必须能启动、能观察、能控制、能记录、能复现。

最小交付：一个工作空间、至少两个功能包、一个 bringup launch、一个 RViz 配置、一个参数 YAML、一个 bag 录制流程和一份系统说明。

## 验收标准

- 每章都有概念解释、命令实验、正确现象、常见错误、自测题和延伸阅读。
- 所有高风险事实都有官方或上游来源支撑。
- 安装方法完整且结构清晰：主线明确，旁路说明适用场景。
- 正文始终围绕 ROS1 入门，不把后续 LoongArch64 研究提前写成主线。
